Modus: Laufen draußen

📍 GPS / Standort

Für die Laufstrecke braucht die App deinen Standort. / Для маршрута приложению нужно твоё местоположение.

So schaltest du den Standort ein / Как включить геолокацию:

iPhone: Einstellungen → Datenschutz & Sicherheit → Ortungsdienste → An. Dann weiter unten „Safari-Websites“ (bzw. deinen Browser) → „Beim Verwenden der App“ und „Genauer Standort“ an. / Настройки → Конфиденциальность → Службы геолокации → Вкл.; ниже «Сайты Safari» → «При использовании», «Точная геопозиция».

Android: Wische von oben nach unten und tippe auf „Standort“. Dann in Chrome: ⋮ → Einstellungen → Website-Einstellungen → Standort → diese Seite erlauben. / Шторка → «Местоположение»; в Chrome: ⋮ → Настройки → Настройки сайтов → Местоположение → разрешить.

Danach hier erneut auf „GPS erlauben“ tippen. / Затем снова нажми «Разрешить GPS».
